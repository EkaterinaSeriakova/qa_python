# BooksCollector

Проект реализует коллекцию книг с группировкой по жанрам.

## Функционал

- Добавление книг в коллекцию.
- Получение списка книг по жанру.
- Валидация входных данных (проверка на дубли, пустые значения).

## Реализованные тесты

| Тест | Описание | Статус |
| --- | --- | --- |
| `test_add_new_book_add_two_books` | Проверка добавления двух книг и их наличия в `books_genre` | ✅ Passed |
| `test_empty_collection` | Проверка поведения при запросе к пустой коллекции | ✅ Passed |
| `test_duplicate_title` | Проверка обработки дубликатов названий (отказ в добавлении) | ✅ Passed |
